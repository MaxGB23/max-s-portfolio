Presidencia Municipal de Acámbaro — Acámbaro, GTO

Desarrollador Full-Stack (Estadía Profesional)
Enero 2025 – Abril 2025

Lideré el desarrollo de una plataforma Full-Stack escalable para digitalizar la gestión de solicitudes de apoyo social, eliminando procesos manuales y mejorando la eficiencia operativa del gobierno municipal.

Logros principales
Digitalización completa del flujo de solicitudes de apoyo social, reduciendo tiempos de respuesta y eliminando el uso de papel.
Implementación de paneles estadísticos en tiempo real que apoyan la toma de decisiones institucionales.
Automatización de la generación de documentos PDF con validez legal.
Mejora en la transparencia y trazabilidad de los procesos administrativos.
Responsabilidades y contribuciones
Diseñé y desarrollé una aplicación Full-Stack utilizando Next.js, TypeScript, PostgreSQL y Prisma.
Implementé autenticación y control de acceso basado en roles (RBAC) por departamento usando NextAuth.
Desarrollé módulos clave para:
Gestión de solicitudes de apoyo
Administración de usuarios
Generación automatizada de documentos legales
Construí dashboards interactivos con Recharts para visualización de datos.
Implementé generación dinámica de documentos PDF con firma electrónica y datos autocompletados.
Desplegué la aplicación utilizando Vercel y base de datos en NeonDB.
Coordiné el desarrollo bajo metodología Scrum, utilizando Jira para la gestión de tareas.
Funcionalidades desarrolladas
Dashboard (Inicio):
Visualización de métricas clave mediante tarjetas y gráficos interactivos.
Gestión de solicitudes:
Tabla con filtros por estado, prioridad y departamento.
Generación de documentos:
Creación de PDFs legales con datos dinámicos y vista previa.
Administración de usuarios:
CRUD de usuarios con asignación de roles y departamentos (acceso restringido a administradores).
Gestión de documentos:
Configuración de plantillas dinámicas (firmantes, logotipos, periodos administrativos).
Tecnologías utilizadas

Next.js · TypeScript · PostgreSQL · Prisma · NextAuth · NeonDB · Tailwind CSS · Shadcn UI · Recharts · Vercel · Jira


Funcionalidades desarrolladas
Dashboard (Inicio):
Visualización centralizada de métricas clave mediante tarjetas (KPIs) como número de solicitudes, estatus y distribución por departamento.
Gráficos interactivos construidos con Recharts para análisis de tendencias, volumen de solicitudes y asignación de recursos.
Actualización dinámica de datos en tiempo real para facilitar la toma de decisiones estratégicas.
Gestión de solicitudes:
Tabla dinámica de solicitudes con paginación, búsqueda y filtros avanzados (estado, prioridad, departamento, fechas).
Flujo completo de gestión: creación, edición, seguimiento y cambio de estatus de solicitudes.
Asignación de solicitudes a departamentos específicos con control de visibilidad por rol.
Registro estructurado de datos del ciudadano solicitante y tipo de apoyo requerido.
Generación de documentos:
Generación automatizada de documentos PDF con datos dinámicos provenientes de cada solicitud.
Vista previa del documento antes de su emisión para validación.
Integración de firma electrónica y estructura adaptable a requerimientos legales.
Autocompletado de información clave: fechas, datos del ciudadano, tipo de apoyo y responsables administrativos.
Administración de usuarios:
Sistema completo de gestión de usuarios (alta, baja, edición).
Implementación de control de acceso basado en roles (RBAC) con segmentación por departamentos.
Restricción de vistas y acciones según permisos (por ejemplo, acceso exclusivo a administradores).
Asignación y modificación dinámica de roles y áreas organizacionales.
Gestión de documentos (plantillas):
Configuración flexible de plantillas de documentos legales.
Personalización de elementos institucionales como nombre del presidente municipal, responsables y logotipos.
Adaptabilidad del sistema a distintos periodos de gobierno sin necesidad de cambios en el código.
Persistencia de configuraciones para generación consistente de documentos oficiales.
