# 🏥 Sistema de Gestión Clínica — Listo para Producción

¿Tu clínica o consultorio aún depende de Excel, agendas manuales o varios sistemas separados?

Desarrollé una plataforma web full-stack que ya está siendo utilizada por un centro real de fisioterapia y rehabilitación. Actualmente cuenta con +3 meses en producción sin caídas, gestionando citas, pacientes y pagos del día a día. Puedo adaptarla o construir una versión a medida para tu negocio.

## 🚀 Funcionalidades principales

### 📅 Agenda clínica inteligente

- Calendario semanal interactivo
- Prevención automática de conflictos
- Control de sesiones (pendiente, asistida, cancelada)

### 👥 Expediente de pacientes

- Alta y búsqueda rápida
- Historial de sesiones y pagos
- Seguimiento individual

### 💳 Paquetes y control de pagos

- Venta de paquetes de sesiones
- Balance por paciente
- Registro de ingresos

### 📊 Analítica del negocio

- Ingresos mensuales
- Pacientes activos
- Ganancias
- Métricas operativas

**Visualización de datos:**

- Filtros por periodo: últimos 30 días, 3 meses y 1 año
- Panel principal basado en tarjetas (cards) y gráficos con resumen mensual, últimos 3 meses e histórico.

### 🌐 Landing page pública

- Optimizada para SEO
- Captación de nuevos pacientes
- Integrada con el sistema interno

### 🔒 Seguridad y roles

- Accesos por tipo de usuario
- Manejo seguro de sesiones

## 🛠️ Tecnología

`Next.js · TypeScript · PostgreSQL · Prisma · Tailwind · Vercel`

Arquitectura modular, rápida y preparada para escalar a múltiples especialidades.

## 💡 Ideal para

- Fisioterapia y rehabilitación
- Psicología y nutrición
- Odontología y consultorios médicos
- Centros que trabajan por sesiones o paquetes
