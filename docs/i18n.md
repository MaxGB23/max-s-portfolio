# I18n — Qué hacer cuando tocas texto visible

Regla de oro: **ningún texto visible va hardcodeado en un componente**. Va como clave en `data/translations.ts` (ES + EN) y se renderiza con `t()`.

Canon de la feature: `docs/ideas-features/language.md`.

## Quick path

1. ¿Es **chrome** (label, título, botón, badge, aria, alt, metadata) o **data** (contenido de proyectos/planes/productos)?
2. **Chrome** → añade la clave en `data/translations.ts` con prefijo por dominio (`nav.*`, `hero.*`, `common.*`, `section.<sección>.*`) en **ambos** idiomas. El build falla si falta una — el tipado lo garantiza.
3. En el componente: `const { t } = useLanguage()` (componentes client) y renderiza `t("clave")`. En **server components** (ej. `app/proyectos/[id]/page.tsx`): resuelve el idioma con `cookies()` — no hay hook.
4. Verifica: `pnpm exec tsc --noEmit` + `pnpm build`.

## Decisiones

| Situación | Hacer |
|---|---|
| Texto de UI (chrome) | Clave en `translations.ts` + `t()` |
| Contenido de `data/projects.ts`, `tiers[]`, `products[]` | **NO** va a `translations.ts`. Queda en ES hasta el modelo bilingüe (pendiente). Marca la deuda si la editas |
| Nombres propios, marcas, URLs, rutas de archivos | No traducir |
| Plantilla con variable | Clave con `{placeholder}` + `.replace("{placeholder}", valor)` |
| Pares responsive (lg vs mobile con copy distinto) | Dos claves (ej. `metricsSubtitleLg` / `metricsSubtitle`) |
| Mismo texto en varias secciones | Clave compartida `common.*` (ej. `common.caseStudyOfTitle`, `common.backToProjects`) |
| React `key` | Siempre data-driven o índice — nunca una traducción |
| Claves con `**markdown**` (futuro data bilingüe) | Preservar los `**` al traducir |

## Checklist

- [ ] Clave nueva en `es` **y** `en` (el `satisfies Record<TranslationKey, string>` ya lo exige)
- [ ] `t()` llamado dentro del componente (nunca en una constante module-scope de un client component)
- [ ] Aria-labels y `alt` traducidos si llevan significado para el usuario
- [ ] Sin claves hardcodeadas ni textos visibles sueltos en el diff
- [ ] `pnpm exec tsc --noEmit` y `pnpm build` en verde
