# Problemas de Carga (Flash of Unstyled Content/Theme) (✅ RESUELTO)

Actualmente, al entrar a la página por primera vez, ocurren dos problemas principales:

1. **Parpadeo del Tema (Theme Flashing):** 
   El tema realiza un pequeño salto al cargar. Si el tema preferido es oscuro (*dark*), el navegador aplica inicialmente el modo claro (*light mode*) y luego cambia al oscuro tras unos milisegundos, lo que resulta en una mala experiencia de usuario.

2. **Salto de Animaciones (Layout Shift/FOUC):** 
   El texto del Hero y otros elementos aparecen inmediatamente al cargar la página, pero después de unos milisegundos se aplican las animaciones, provocando un salto visual perceptible.
